Test 5: Zero-Shot Generalization

STATUS: SUCCESS

Predicting pandemic dynamics in unseen states (West Coast) using a model trained only on the East Coast.

🧪 Experiment Summary

Methodology: We took the pre-trained model from Test 3 (ExplicitGNN with Dropout) and applied it to a completely new graph of 5 states (PA, MI, WA, MA, AZ). No retraining was performed. We transferred the GNN weights and initialized latent variables using statistical transfer.

result: The plots below show the prediction (Red) vs Real Data (Blue) for 401 days. The vertical dashed line at Day 180 marks the end of the training horizon used for the source model.

💡 Key Insights

  • Universal Dynamics: The model successfully decoupled "Physics" (GNN weights) from "Geography" (Graph Topology). It works on graphs it has never seen.
  • Temporal Extrapolation: even 200 days after the training window ends, the model predicts coherent waves, not chaos.
  • Latent Transfer: Initializing latents with $\mu, \sigma$ from the training set was crucial to avoid flatline predictions.
