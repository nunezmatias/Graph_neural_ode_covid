This folder contains the scripts and data required to perform variable selection, training with time-lagged covariates, and stochastic evaluation of COVID-19 case projections.

# Data Overview

## Core Dataset: `Data/data_all.npz`
This file contains the complete set of variables. The indices for the variables are as follows:

| Index | Variable | Source/Type |
| :--- | :--- | :--- |
| 1 | **Daily COVID-19 cases** | Target Variable |
| 2 | CLI community | Survey |
| 3 | Doctor visits | Medical Records |
| 4 | Events indoor (last 24h) | Survey |
| 5 | Google search: "Cough" | Search Trends |
| 6 | Google search: "Fever" | Search Trends |
| 7 | Google search: "Nasal Congestion" | Search Trends |
| 8 | Google search: "Sore Throat" | Search Trends |
| 9 | Mask usage (last 7 days) | Survey |
| 10 | Public Transit usage | Survey |
| 11 | Working outside of home | Survey |

## Metadata & Mapping
* `us_pop_state.csv`: 2020 Census data for 49 selected US states.
* `state_cluster_mapping.jld2`: A dictionary mapping states to their respective clusters: `{Hubs, Connectors, Periphery}`.

# Variable Analysis

`var_selection.jl`  
This script performs two main tasks:
1. **Hierarchical Clustering**: Clusters covariates (variables 2–11) based on mutual correlation.
2. **Lag Analysis**: Analyzes the correlation between covariates (shifted in time) and the target variable to determine optimal lead times.

---

# Training

`auto_train_shift.jl`  
A 5-phase training strategy that allows for custom variable selection and specific time lags. 

### Usage
Pass the variable indices (from the table above) and their corresponding lags using the `--idx` and `--lag` flags.

**Example:** Training with CLI Community (Index 2) at a 7-day lag and "Fever" searches (Index 6) at a 14-day lag:
```bash
julia auto_train_shift.jl --idx 2,6 --lag 7,14
```

---

# Evaluation

`evaluate_unseen_stoch.jl`  
This script utilizes the optimized parameters generated by `auto_train_shift.jl` to perform comprehensive simulations on both training and testing datasets.

## Key Features:
* **Stochastic Sampling**: Latent variables are sampled **100 times** to account for their inherent stochastic nature, providing a distribution of possible outcomes.
* **Error Analysis**: The script automatically calculates absolute and relative errors for each state.

## Outputs:
* **Tables**: State-wise error metrics are saved in the `Tables/` directory.
* **Plots**: Visualization of results, including error boxplots and heatmaps, are saved in the `Plots/` directory.

**IMPORTANT! Manual Configuration Required:** 
1. **Variable Mapping**: Variable indices and time lags must be updated **manually** within the script to match your training configuration.  
2. **File Paths**: If you are testing multiple parameter sets, ensure you update the output file paths in the script manually to prevent data from being overwritten.
